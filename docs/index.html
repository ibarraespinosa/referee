Built Specifically for Reviewers

No bloat, no subscription fees. Just the reviewer tools you need every day.

🖍️

1-Click Text Highlighting

Drag across text to instantly apply standard reviewer color highlights. Seamless selection and grouping across lines.

📌

Sticky Notes & Callouts

Drop comment pins anywhere on equations, paragraphs, or diagrams. Keep notes organized with customizable reviewer tags.

📋

Live Review Drawer

All comments and highlights appear in an interactive sidebar grouped by page. Click any item to jump directly to it.

🚀

1-Click Review Export

Export all your notes, quotes, and critique into clean Markdown or Plain Text ready for OpenReview, HotCRP, or EasyChair.

✍️

Pen, Underline & Shapes

Circle equations with the freehand pen, underline statements, strike out words, or draw bounding boxes around figures.

⚖️

100% ISO 32000 Compliant

All annotations are native PDF annotations. Authors and editors opening your files in Acrobat, Okular, or Chrome see them natively.

Installation & Setup

Get started in under 30 seconds on Ubuntu and Linux distributions.

Option 1: Automated 1-Click Installer (Recommended)

Clones the repo, installs the CLI command, and sets up your desktop application menu entry:

git clone https://github.com/ibarraespinosa/referee.git
cd referee
./install.sh

Option 2: Install via Pip

pip install --user . --break-system-packages

Keyboard Shortcuts Cheat Sheet

Review at lightning speed using full keyboard shortcuts.

Shortcut Tool / Action Description
Shift + H Highlight Activate highlight tool and drag across text
N Sticky Note Click anywhere to place a review comment pin
U / S Underline / Strikeout Suggest text additions or deletions
T Margin Text Box Type text directly on the page margin
P / R Pen / Rectangle Circle formulas or frame figures and tables
V Select / Pointer Select annotations or inspect review notes
Del Delete Mark Remove the currently selected annotation
Ctrl + F Find Text Search across document with match counter
Ctrl + S Save PDF Save with standard ISO 32000 PDF annotations
Ctrl + Z Undo Undo last review annotation
F9 Toggle Sidebar Show/hide thumbnails and review notes drawer
